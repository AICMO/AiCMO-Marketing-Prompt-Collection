## Overview
This prompt builds a fully automated, AI-driven proof-of-concept (POC) orchestration system that structures technical evaluations, automates stakeholder communication, tracks success criteria, and converts successful POCs into closed deals with minimal human effort. Use it when enterprise prospects demand a structured evaluation before signing, and your team needs to run multiple POCs simultaneously without losing deal momentum.

## Troubleshooting

**Issue 1: Prospect won't agree to formal success criteria before POC starts**
This is the #1 POC failure mode. Fix: Reframe success criteria as "guardrails that protect their time investment, not a vendor scorecard." Offer to draft all criteria yourself and ask them to approve/edit — lower friction than asking them to create from scratch. If they still resist, this is a disqualifying signal: escalate to your economic buyer contact before committing POC resources.

**Issue 2: POC drags past 45 days with no decision**
Root cause is almost always economic buyer disengagement or scope creep. Fix: Use the Week 3 check-in to explicitly confirm the decision date and who makes it. If the date has shifted, renegotiate the MSP with a hard "POC extension = formal project commitment" requirement. Run the Day 35 escalation sequence immediately if health score has been Yellow for 2+ consecutive weeks.

**Issue 3: Technical integration fails mid-POC, killing momentum**
Do not pause the POC while engineering fixes the issue. Fix: Pivot immediately to a manual data demonstration using pre-loaded sample data that mirrors the prospect's environment. This proves the use case value while integration is resolved in parallel. Frame to the champion: "We're running two tracks — the technical fix (owner: [engineer], ETA: [date]) and the business value demonstration — so you see the full picture on time."
