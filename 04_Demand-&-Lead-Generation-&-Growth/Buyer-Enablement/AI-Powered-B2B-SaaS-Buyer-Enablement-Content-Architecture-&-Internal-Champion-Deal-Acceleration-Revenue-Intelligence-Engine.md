## Overview
This prompt builds a fully automated, AI-driven buyer enablement system that equips internal champions with personalized content packages—business cases, ROI models, procurement playbooks, and objection responses—so they can sell your product internally. Use it when deals stall in mid-to-late pipeline stages because champions lack the tools to navigate procurement, security reviews, legal, and C-suite sign-off.

## Integration Tips

- **Salesforce/HubSpot CRM**: Create a deal stage trigger that automatically fires the buyer enablement content package to the sales rep's queue. Map each Module to a CRM deal stage. Use custom fields to track which enablement assets have been sent and opened.
- **Seismic / Highspot / Showpad**: Upload each module as a trackable content asset. Configure link tracking so sales reps can see when a champion shares the business case internally.
- **Mutiny / Qualified / 6sense**: Use account-level personalization to pre-populate the buyer enablement templates with account-specific data (company size, industry benchmarks) before the sales rep sends.
- **Slack/Teams Integration**: Configure an alert that fires in the #revenue-operations channel when a buyer enablement kit is opened by a new stakeholder (indicating the champion is sharing internally).
- **Zapier/Make.com Automation**: Build a Zap that: (1) detects deal stage change in CRM → (2) generates personalized content package via API call to AI model → (3) attaches to deal record → (4) sends Slack notification to sales rep with "Your buyer kit is ready" message.
- **Google Sheets ROI Calculator**: The ROI calculator formula can be turned into a Typeform + Google Sheets integration where the champion fills in inputs and receives a branded PDF output automatically via Zapier.
- **Notion / Confluence**: Template the buyer enablement kit as a Notion page that updates dynamically based on deal metadata. Champions can duplicate and customize without needing sales rep help.

## Troubleshooting

**Issue: Generated business case feels generic and the CFO won't engage with it.**
*Fix*: The prompt requires specific customer proof data. Ensure you provide real customer names and specific outcome metrics (not ranges). Replace any remaining "[BRACKETS]" with real company-specific data. The CFO objection responses must reference your actual certifications (SOC 2 Type II vs. a generic "we're secure" statement) and real customer names the CFO can verify independently.

**Issue: Champion shares the kit internally but deals still stall at legal/procurement.**
*Fix*: The most common stall in legal/procurement is missing documentation. Run Module 3d (Legal/Procurement Accelerator) first and proactively send the Security Questionnaire Pre-fill and DPA summary before procurement asks for it. The goal is to answer questions before they're asked — not to respond after they create a queue.

**Issue: Sales reps aren't using the buyer enablement content.**
*Fix*: The content must be in the rep's workflow, not in a separate portal. Integrate with your existing sales engagement platform (Outreach, Salesloft, Apollo) so the buyer enablement sequences appear as ready-to-use email templates triggered by deal stage. If reps must log into a separate system, adoption will be under 20%. Make it a 1-click action from the CRM deal record.
