## Integration Tips

- **Salesforce / HubSpot CRM:** Create a custom "Proof Asset Deployed" field on the Opportunity object — log which tier of proof was used and when. Build a dashboard showing proof-influenced pipeline vs. non-influenced. Trigger proof mobilization workflow when deal stage changes to "Evaluation" and days-in-stage exceeds 14.
- **Reference Management (ReferenceEdge, Influitive, Deeto):** Sync reference customer profiles with deal context — automate reference match suggestions when AEs log an opportunity. Set automated reference fatigue alerts (max 3 uses per quarter per customer).
- **Seismic / Highspot / Showpad:** Tag all proof assets by industry, company size, persona, and competitor displacement — allow AEs to filter by deal context and surface the right evidence in seconds. Track which assets are shared and opened by prospects.
- **Slack / Teams Integration:** Create a #deal-proof-requests channel where AEs can drop a deal brief and marketing responds with a Tier 1 proof package within 4 business hours — set SLA and track response time.
- **G2 / Gartner Peer Insights:** Build a curated "review spotlight" library by vertical and use case — pre-select the 3-5 most relevant reviews per ICP segment so AEs don't have to search.
- **Notion / Confluence Reference Library:** Maintain a living reference database with fields: company size, industry, use case, outcome metrics, availability status, last used date, reference contact name — update monthly.

## Troubleshooting

**Problem:** Reference customers are fatigued or unavailable, leaving you without a live reference for a critical deal.
**Solution:** Build a reference bench of 3x your active deal count. Identify "micro-references" — customers willing to send a written testimonial or respond to an email rather than joining a call. Create a "reference academy" where top customers are compensated with executive access, early feature previews, or co-authorship credit on case studies — this expands pool and deepens engagement.

**Problem:** The proof assets you have don't match the prospect's exact industry, and the prospect says "but you don't have any customers like us."
**Solution:** Lead with the adjacent match — find a case study in a neighboring industry with the same operational challenge and use case, not the same SIC code. Frame it as: "We don't have a published case study from your exact sub-vertical yet, but Meridian's situation — a mid-market FinTech with compliance-heavy operations — mirrors exactly how [Adjacent Company] approached their transformation. Here's why this applies..." Then use this as a signal to accelerate case study production with your closest matching customer.

**Problem:** The sales team doesn't tell marketing about stalled deals until it's too late, and proof mobilization is reactive and rushed.
**Solution:** Create a proactive pipeline alert — set a Salesforce/HubSpot trigger that automatically notifies the marketing pipeline team when any deal has been in a stage for more than 10 days. Marketing initiates the proof audit (which objections need evidence?) without waiting for the AE to ask. This converts marketing from reactive to proactive pipeline support and shortens the average proof deployment window from 5+ days to 24-48 hours.
