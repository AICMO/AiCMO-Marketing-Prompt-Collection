## Integration Tips

**6sense / Bombora / G2 Buyer Intent → Sequence Trigger:**
- Use webhook or native CRM integration to push intent signals into HubSpot or Salesforce as custom object events
- Set workflow enrollment trigger: "Intent Signal Score > 70 AND Tier = 1" → enroll in Tier 1 sequence in Outreach/Salesloft
- Map signal metadata (signal type, pages visited, duration) to sequence personalization tokens

**Outreach / Salesloft Setup:**
- Create one sequence per Tier (5 sequences total)
- Use dynamic fields to inject signal context into each step
- Set "auto-pause on reply" and "auto-complete on meeting booked" using native integrations

**Slack SDR Alert Automation (via Zapier or native):**
- Trigger: Prospect opens email 3+ times without reply → post to #hot-leads Slack channel
- Message format: "🔥 {First Name} at {Company} has opened our Tier 1 sequence 3x in {X hours}. Signal: {Signal Type}. [View in Salesforce] [View sequence activity]"

**HubSpot Workflow:**
- Property trigger: `intent_tier = 1` AND `sequence_enrolled = false`
- Action: Enroll in sequence + create task for assigned SDR + add to LinkedIn Matched Audience for Tier 1 display retargeting

**LinkedIn Campaign Manager:**

## Troubleshooting

**Problem:** Sequence reply rates are high but meeting conversion is low (<8%).
**Solution:** The CTA is likely too vague or the ask is too large. Audit every CTA in the sequence — switch from "book a 30-minute demo" to "Is a 15-minute call this week worth it?" Reduce friction on the calendar link (use Calendly with 15-minute slots visible). Also check that meeting confirmation emails include a specific agenda so prospects know exactly what to expect.

**Problem:** Tier 1 sequences are firing for low-quality prospects who don't fit ICP.
**Solution:** Add a secondary ICP filter before sequence enrollment. Use Clearbit Enrichment or Clay to validate company size, industry, and tech stack signals before the intent signal alone triggers enrollment. Create a "pre-qualification gate" workflow step that checks 3 ICP criteria; only enroll if ≥2 are met.

**Problem:** SDRs are ignoring the sequence and doing their own outreach in parallel, creating duplicate contact.
**Solution:** Create a Salesforce/HubSpot lock field: "Sequence Active = True" — any prospect with an active sequence should require SDR to acknowledge before manual outreach is allowed. Run a weekly 15-minute SDR sync to review Tier 1 active sequences and divide ownership clearly between automated touchpoints and human-escalation touchpoints.
