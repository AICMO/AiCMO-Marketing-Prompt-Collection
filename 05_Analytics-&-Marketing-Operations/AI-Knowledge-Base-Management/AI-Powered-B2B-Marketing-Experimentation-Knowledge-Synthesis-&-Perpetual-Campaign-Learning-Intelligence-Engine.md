## Troubleshooting

**Problem: Experiment records are incomplete — teams document results but skip the Hypothesis Layer and Insight Layer**
Solution: Make insight extraction non-negotiable by gating campaign budget approval on completed knowledge records. Alternatively, use an AI agent to auto-populate the Insight Layer from raw results data: "Given these A/B test results [paste], generate a structured buyer insight statement following this format: [paste format]." The AI draft reduces entry friction to a 5-minute review rather than a 20-minute writing task.

**Problem: Buyer truth statements go stale — the library accumulates 200+ entries but nobody maintains decay signals**
Solution: Implement a hard limit of 50 active Confidence A statements at any time. New entries require retiring or downgrading an existing entry to Confidence C (pending replication). This forces the team to actively maintain knowledge quality rather than accumulate volume. Set a quarterly "knowledge pruning sprint" of 2 hours where the team votes on which Confidence B and C insights to archive vs. retest.

**Problem: AI tools generate outputs that ignore the context modules — the investment in building the library doesn't transfer to output quality**
Solution: The context module must be injected in every prompt, not stored passively. Build a prompt template library where every AI generation request starts with the relevant AI Agent Context Package pre-pended — segment-specific, channel-specific, and anti-pattern guardrails included. Test AI output quality with and without context injection using a structured scoring rubric to quantify the ROI of your knowledge investment to leadership.
