## Integration Tips

**HubSpot:** Build beta program as a Workflow with lifecycle stage "Beta Participant." Use contact properties to track: beta_cohort_week, survey_response_count, champion_score, advocate_actions_completed. Trigger champion conversion sequences via workflow enrollment when champion_score ≥ 3.

**Mixpanel/Amplitude:** Create a "Beta Cohort" user segment. Build funnel: Invited → Accepted → Setup Complete → First Core Action → Week 4 Active → Champion Convert. Share funnel access with PM and CS leads weekly.

**Intercom:** Use company tags ("Beta-[FeatureName]-Cohort") to segment in-app messaging. Trigger Day 0 welcome checklist via Product Tours. Set up feedback widget as a Message triggered by event completion.

**Notion:** Create a shared Design Partner Portal with: program overview, weekly session recordings, roadmap updates, and a "your feedback → our changes" changelog that shows participants direct impact of their input.

**Zapier:** Connect survey tool (Typeform/Tally) → HubSpot to update champion_score property on survey completion. Connect HubSpot workflow → Slack to alert CSM when an account's champion_score reaches threshold.

**G2:** Use G2's review collection API or their email integration to trigger direct review requests. Personalize the pre-fill URL with participant's name and company for lower friction.

## Troubleshooting

**Problem: Beta recruitment response rate below 30%**
Fix: Audit the personalization layer — generic invitations kill response rates. Pull the participant's actual feature request from your product board and reference it explicitly ("You requested [exact feature] 4 months ago — here it is"). If you don't have request data, use usage data ("You've spent X hours on [manual equivalent workflow]"). Also check send timing: Tuesday-Thursday 9-11am recipient local time outperforms all other windows for B2B.

**Problem: Survey fatigue drops response rate below 40% by Week 4**
Fix: Shorten surveys aggressively — 3 questions maximum by Week 3. Switch to in-product pulse surveys (1 question, triggered immediately after feature use) rather than email surveys. Reward consistency publicly in the Slack community: "Top 10 most responsive Founding Cohort members this week" with a small recognition (not incentive) drives completion through social accountability.

**Problem: Champion conversion asks generating silence or polite declines**
Fix: You're asking too early or too much at once. Sequence matters — never ask for a case study before you have a quote. Check your champion readiness signals: if they haven't hit 3/5, they're not ready. Also audit the value exchange: case study participants need to see career upside (byline in your publication, LinkedIn feature, executive access), not just reciprocity. Reframe the ask as co-authorship, not a marketing favor.
