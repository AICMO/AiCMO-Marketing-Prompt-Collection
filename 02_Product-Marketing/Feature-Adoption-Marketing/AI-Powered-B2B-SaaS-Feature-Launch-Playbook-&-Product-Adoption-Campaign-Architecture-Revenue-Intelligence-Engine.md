## Integration Tips

- **HubSpot:** Set up a Workflow with enrollment trigger "Contact property: Feature activation = false AND days since launch ≥ 4" to automate the email sequence. Use custom properties for health_score and feature_adoption_stage synced from your product database via HubSpot API.
- **Intercom:** Use Series to build the in-app message flows. Set Series entrance criteria on user property `feature_enabled_date IS SET` and `feature_first_win_completed IS NOT SET`. Tag users as "Feature Champion" when the 5th interaction event fires.
- **Pendo:** Build the onboarding walkthrough as a Pendo Guide with step-completion tracking. Export adoption funnel data to Salesforce as Account-level fields for CSM dashboards.
- **Salesforce:** Create a Feature Adoption field on the Account object with picklist values (Unaware → Activated → First Win → Habitual → Champion). Trigger CSM task creation when account stays in "Activated" for 14+ days without progressing.
- **Zapier / Make:** Connect product event webhooks → Zapier → HubSpot to update adoption stage in real time without engineering involvement. Use a Google Sheet as staging table if direct API access isn't available.
- **Gong:** Filter call recordings by "mentioned [feature name]" to identify champion accounts and at-risk accounts having negative conversations about the feature. Feed signals to CSM queue.

## Troubleshooting

**Problem: Email open rates are below 25% on the launch announcement.**
Solution: Check whether you're sending from a personal sender name (e.g., "Sarah from Kintsugi" vs. "Kintsugi Team"). Personal sender addresses consistently outperform team/brand senders by 15-40% in B2B lifecycle email. Also verify the subject line isn't triggering spam filters — avoid words like "free," "guaranteed," or excessive capitalization.

**Problem: Activation rate is high but "First Win" completion drops off — users try the feature once and don't return.**
Solution: The onboarding walkthrough is failing to deliver a meaningful outcome in the first session. Shorten your "First Win" definition — if it requires 3+ steps, reduce to 1 step that produces a visible, shareable artifact (a report, a flagged deal, an auto-filled CRM field). Users need to feel smart immediately. Re-trigger the Day 4 "use-case walkthrough" email to non-completers with a simplified "Try this one thing in 60 seconds" CTA.

**Problem: CSMs aren't using the enablement brief or initiating adoption conversations in QBRs.**
Solution: Remove the brief from their inbox and add it directly to the QBR prep doc template in Salesforce. Create a mandatory Salesforce task auto-assigned to each CSM: "Feature adoption check-in call — [Account Name]" triggered 10 days post-launch. If CSMs see adoption conversations as optional, they'll deprioritize them. Make it part of the renewal-risk workflow, not a standalone marketing ask.
