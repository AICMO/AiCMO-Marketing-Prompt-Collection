## Overview

This prompt builds a systematic, AI-powered feedback loop between Product Marketing and Sales that continuously improves win rates by mining deal outcomes, surfacing messaging gaps, and auto-updating positioning — closing the loop that most B2B SaaS companies leave open. Use it when win rates are stagnating, messaging feels disconnected from what buyers actually say, or PMM output isn't visibly tied to revenue outcomes.

## Integration Tips

**Salesforce:**
- Create a custom Salesforce report: "PMM Intelligence Dashboard" — filtered to last 30 days of closed deals, grouped by loss reason and key objection field
- Set up a Salesforce Flow that emails the PMM lead when 3+ deals close with the same loss reason in a 7-day window — automated trigger for 7-day cycle
- Use Salesforce Chatter on deal records: ask reps to tag @PMM when they hear something novel — lower friction than CRM field entry

**Gong:**
- Build a Gong Initiative called "PMM Signal Capture" — tracks calls with your custom tag taxonomy
- Use Gong's AI summary feature: create a custom prompt that extracts "buyer language for PMM" from call recordings — run weekly, pipe summary to PMM Slack channel
- Set up Gong alerts for rep-PMM collaboration: notify when a rep mentions a competitor but doesn't have a strong counter-response (identify coaching opportunity)

**Highspot / Seismic / Showpad:**
- Track which PMM assets appear in Closed Won vs. Closed Lost deals via document analytics — builds content utilization attribution
- Set up "recently updated" notification push to AEs when PMM ships messaging updates — increases adoption vs. email announcements
- Create a "Field Intelligence Inbox" in your enablement platform where reps submit deal insights directly — bypasses CRM friction

**HubSpot/Marketo:**
- Build a "win rate cohort" dashboard: group deals by the month when PMM launched a major messaging update, compare win rates before/after — demonstrates PMM marketing influence
- Use MAP behavioral data to correlate content engagement with deal progression: which PMM content pieces appear in deals that move from Stage 3 to Stage 4 fastest

**Notion/Confluence:**
- Create a "Living Messaging Changelog" page: every PMM update is logged with date, trigger (what field data caused it), assets updated, and expected outcome — builds institutional memory
- Link directly from CRM loss reason fields to relevant battlecard sections — reps who log a loss can immediately see the updated PMM response

## Troubleshooting

**Problem: Reps don't fill in CRM fields consistently, undermining data quality**
Solution: Work with Sales Ops to make 2-3 fields required for stage progression, not just deal close. Required at Stage 5 entry (not close) catches the information while the deal is fresh. Pair with a framing message from the VP of Sales: "These 3 questions help PMM make your battlecards more useful. 30 seconds now saves you 30 minutes per deal later." Never position it as compliance — position it as "help us help you."

**Problem: Sales team dismisses PMM intelligence reports as "not actionable"**
Solution: Change the format. Stop sending a data report and start sending "One PMM Action This Week" — a single Slack message every Monday that says: "Based on last week's data, here's the ONE thing to try differently in your next demo." Specificity beats comprehensiveness. Then track if deals where reps apply that one thing have different outcomes.

**Problem: Win rate doesn't improve despite messaging updates**
Solution: Separate the diagnosis. If reps aren't using updated materials → adoption problem (not messaging). If reps use materials but buyers don't respond → messaging problem (iterate faster, test more variants). If buyers like messaging but deals still stall → likely a sales execution, pricing, or product issue that PMM can't solve alone. The PMM attribution model helps isolate which of the three is the real blocker — don't let PMM take blame for non-PMM problems.
