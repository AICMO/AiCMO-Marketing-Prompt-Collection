## Troubleshooting

**Problem:** CRM data is too incomplete — many fields missing or inconsistently filled, making pattern analysis unreliable.
**Solution:** Don't try to analyze all fields — focus only on the 3-4 most consistently populated fields (deal size, lead source, industry, champion title). Run the analysis on those and treat missing fields as a separate data quality initiative. Use the prompt to create a "CRM hygiene scorecard" that identifies which fields have <80% completion and prioritizes them for sales training.

**Problem:** Sample size is too small (fewer than 30 closed-won deals in the analysis period) to find statistically significant patterns.
**Solution:** Extend the analysis window to 18-24 months. For segments with fewer than 10 data points, use qualitative analysis from sales call notes and win/loss interview summaries rather than quantitative. Flag insights as "directional hypotheses to validate" rather than confirmed patterns. Build a 90-day data collection sprint to gather richer win data going forward.

**Problem:** The winning patterns identified contradict the current ICP that marketing is already targeting, creating internal political friction.
**Solution:** Frame the analysis as "refining" not "invalidating" the current ICP — present it as increasing precision within the existing targeting framework. Run a 90-day A/B test: 50% of new outbound uses existing ICP, 50% uses new data-driven ICP, compare win rates. Let data resolve the disagreement rather than debate.
