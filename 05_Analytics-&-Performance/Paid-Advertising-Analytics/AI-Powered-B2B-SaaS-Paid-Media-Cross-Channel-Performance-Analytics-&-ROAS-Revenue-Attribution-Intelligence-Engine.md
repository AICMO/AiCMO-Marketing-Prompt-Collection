## Integration Tips

- **Salesforce / HubSpot:** Export campaign influence reports (multi-touch), opportunity source data, and closed-won revenue by lead source for CRM-sourced ROAS calculation. Match against platform-reported conversion data to calculate attribution gaps.
- **Google Ads + GA4:** Use Google Ads "Search term report" for negative keyword mining; GA4 "Assisted conversions" report for full-path attribution; import Salesforce/HubSpot offline conversions to optimize toward pipeline (not just form fills).
- **LinkedIn Campaign Manager:** Enable Revenue Attribution Report (if connected to CRM) for LinkedIn-sourced pipeline. Use Insight Tag + Matched Audiences for retargeting. Export Document Ad performance separately — it often has 3–5x better CPL than standard Sponsored Content.
- **Supermetrics / Funnel.io / Windsor.ai:** Aggregate all channel spend and performance into a single Google Sheets or BigQuery dashboard. Automate weekly pulls so this analysis runs on fresh data every Monday.
- **Looker Studio / Tableau:** Build a cross-channel ROAS dashboard with drill-down by campaign type, audience segment, and creative format. Publish as a live link for weekly CMO review.
- **Zapier / Make:** Set up automated alerts when any channel's Pipeline-ROAS drops below threshold (e.g., LinkedIn Pipeline-ROAS < 10x for 7 consecutive days) — triggers Slack alert to demand gen team.

## Troubleshooting

**Problem:** Platform-reported ROAS looks strong but CRM shows minimal pipeline from paid channels.
**Solution:** This is a classic attribution inflation issue. Check: (1) Are form fills being double-counted via both Google Tag Manager and a CRM form handler? (2) Is LinkedIn view-through attribution window set to 30 days, counting users who saw an ad and converted organically? (3) Is the UTM parameter chain intact from ad click to CRM lead source field? Run a 2-week UTM audit and reduce LinkedIn view-through window to 7 days as a starting point.

**Problem:** Can't calculate pipeline-per-dollar because CRM doesn't reliably capture lead source on all opportunities.
**Solution:** Before running this analysis, fix source capture: (1) Make "Lead Source" a required field in CRM for all new opportunities. (2) Implement a self-reported attribution question in your demo request form ("How did you first hear about us?"). (3) Use Clearbit/Apollo enrichment to fill missing company data that helps match anonymous ad clicks to known accounts. Run this analysis with the data you have, but caveat all ROAS numbers with the % of opportunities missing source data.

**Problem:** Budget reallocation is blocked because the CFO requires incrementality proof before moving spend off Google.
**Solution:** Design a geo-based holdout test: pause Google Ads in 2 similar-sized markets for 4 weeks while maintaining spend in 2 control markets. Measure pipeline creation rate difference between test and control markets. This is the only way to measure true incrementality without a $200K MMM engagement. Present the test design to finance as "spending the same budget, just rearranging when and where to generate proof."
