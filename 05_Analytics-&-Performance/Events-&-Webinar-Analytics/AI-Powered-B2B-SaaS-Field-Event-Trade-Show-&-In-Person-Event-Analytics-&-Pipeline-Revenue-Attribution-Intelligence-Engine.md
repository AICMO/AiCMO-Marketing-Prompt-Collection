## Integration Tips
- **Salesforce**: Create a custom "Event Source" field on Opportunity object; use Campaign Influence reports (Primary Campaign Source + multi-touch) to pull event-attributed pipeline automatically. Set up Salesforce Campaign Hierarchy: Event (parent) → Pre-Event Outreach, Booth Leads, Hosted Dinner (child campaigns)
- **HubSpot**: Use the Events tool + Contact Activity Timeline to associate event attendance with deal creation dates; build Event ROI dashboards in HubSpot Reporting with custom date-range attribution windows
- **Splash / Cvent**: Export attendee + check-in data, match on email to CRM contacts using deduplication via Dedupely or RingLead, create matched list for SDR follow-up within 2 hours of event close
- **6sense / Bombora**: Overlay intent data on event attendee lists to identify accounts showing buying signals — prioritize high-intent accounts for immediate SDR outreach over generic follow-up sequences
- **Tableau / Looker**: Build Event Portfolio Dashboard pulling from Salesforce Campaigns; automate monthly ROI refresh to compare events side-by-side; embed in marketing operations Slack channel
- **Google Sheets / Notion**: Build a lightweight event ROI tracker template: columns for all cost categories, leads, pipeline stages, with automated ROI calculations — share with VPs for real-time updates during event execution

## Troubleshooting

**Problem:** Badge scan data doesn't match CRM contacts — low match rate makes attribution unreliable.
**Solution:** Require email capture at badge scan (not just name/company). Use enrichment tools (ZoomInfo, Clearbit) to match by name + company when email is missing. Pre-load event attendee list into CRM 2 weeks before event so SDRs can pre-qualify and create contacts for top ICP accounts before the event starts.

**Problem:** Sales team doesn't update CRM opportunity source, so event influence is invisible in reports.
**Solution:** Create a semi-automated process: run a weekly CRM audit matching new opportunities created within 30 days of an event to the event attendee list. If contact attended event and opportunity was created in window, auto-tag as "Event Influenced" and alert the account owner to confirm. Use Salesforce Process Builder or HubSpot Workflows to automate the match and flag.

**Problem:** Attribution window debates — sales says the event "didn't really close the deal," marketing says it was the primary source.
**Solution:** Use a two-metric model presented to leadership: (1) "Event Sourced" = opportunity created within 14 days of event, event contact was first meaningful touch; (2) "Event Influenced" = event contact within 6 months, deal closed within 12 months. Present both metrics side by side. Let sales and marketing agree upfront on definitions before the event — not after. Document the definition in a Revenue Attribution Governance doc signed off by CRO and CMO.
