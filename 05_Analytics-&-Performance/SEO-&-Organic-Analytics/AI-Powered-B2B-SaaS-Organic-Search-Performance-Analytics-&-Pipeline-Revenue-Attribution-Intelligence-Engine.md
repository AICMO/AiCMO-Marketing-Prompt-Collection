- Tag all organic-sourced contacts with "Original Source = Organic Search" in your CRM and create a campaign influence report joining first-touch source to pipeline amount — paste this directly as your pipeline data input

## Troubleshooting

**Problem: Organic traffic data doesn't tie to pipeline in your CRM, making revenue attribution impossible**
Solution: Start with a simplified attribution proxy — count all form submissions (demo requests, trial signups, content downloads) from organic landing pages and multiply by your average deal value × win rate. This gives you an estimated pipeline "influence" number even without CRM source tracking. Then implement proper first-touch source tagging in your CRM as a 30-day project running in parallel.

**Problem: The prompt output recommends content refreshes but you can't tell which specific sections to update**
Solution: Run each decaying page URL through a follow-up prompt: "Compare this page [paste URL content] against the current top 3 ranking pages for [target keyword]. List specifically which sections, statistics, examples, and angles are missing from my page that appear in competitors. Output as a line-by-line content gap list." This creates a precise editor brief.

**Problem: Branded search is masking the true performance of non-branded organic — leadership thinks SEO is performing well but the non-branded funnel is actually declining**
Solution: Always segment branded vs. non-branded in your input data (GSC allows this via Search Type filters or brand keyword exclusions). Present two separate scorecards to leadership: "Brand Organic" (direct navigational intent, hard to attribute to SEO investment) and "Non-Brand Organic" (SEO program output, directly tied to content and link-building investment). Non-brand pipeline contribution is your true SEO ROI metric.
