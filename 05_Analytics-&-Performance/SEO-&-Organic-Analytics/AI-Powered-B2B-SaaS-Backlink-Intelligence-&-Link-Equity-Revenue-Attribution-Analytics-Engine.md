## Integration Tips

**Ahrefs Automation:**
- Schedule weekly "New Backlinks" report exports via Ahrefs API → Google Sheets → auto-format as the "Link Velocity & Acquisition" input section. Use the Ahrefs Batch Analysis endpoint to pull DR scores for all new referring domains in bulk.
- Use Ahrefs' "Link Intersect" tool to auto-generate the competitor gap input: pull top 100 domains linking to each competitor but not you, filter by DR 50+, and paste the list directly into the prompt's Competitive Link Intelligence section.

**Salesforce / HubSpot Attribution:**
- Tag all organic-sourced pipeline with "Original Source = Organic Search" and track domain authority milestones as campaign markers in your CRM. Build a Salesforce report joining organic pipeline generated per quarter against DR score at the start of that quarter — this creates the "authority vs. pipeline" correlation data the prompt uses for ROI attribution.

**Digital PR Workflow Integration (Prowly / Prezly / Muck Rack):**
- After each press release distribution campaign, export media coverage placements → run through Ahrefs to get DR scores → paste into the "Link Building Campaign Performance" section to auto-calculate cost-per-DR-point and campaign ROI.
- Set up a Google Alerts monitor for your company name + "link" or "report" mentions → feed weekly into a Notion database → use as input for tracking unlinked brand mentions that can be converted to links via outreach.

**Toxic Link Monitoring (Google Search Console + Semrush):**
- Connect Google Search Console → Semrush Backlink Audit tool for automated toxicity scoring. Set up a monthly Zapier automation: any domain flagged >50 toxicity score → add to Google Sheet → review in bulk → add to disavow file in one batch rather than ad hoc.

**Content Performance → Link Opportunity Mapping:**
- Build a Looker Studio dashboard that joins Ahrefs referring domain count per URL with GA4 organic traffic per URL. Pages with high traffic but low referring domains are your "link gap" pages — automatically surface them monthly as the highest-priority link building targets.

## Troubleshooting

**Problem: You have no organic pipeline data to connect link building to revenue, making ROI justification impossible**
Solution: Build a proxy attribution model using three inputs: (1) average organic conversion rate (form submissions from organic landing pages ÷ organic sessions), (2) average deal value, (3) average win rate. Then map each ranking improvement to estimated traffic delta (use Ahrefs' traffic value per keyword position × estimated CTR change). Multiply traffic delta × conversion rate × ACV × win rate = estimated pipeline value per link campaign. While imperfect, this gives leadership a defensible ROI estimate while you implement proper CRM source tracking in parallel.

**Problem: Competitor backlink gap is so large (3,000+ domains) it feels impossible to close, making leadership skeptical of link building investment**
Solution: Reframe the gap analysis around targeted authority categories rather than raw volume. Identify the 50-100 referring domains that drive the most competitor ranking power (use Ahrefs' "Referring Domains" sorted by DR, filter for those with contextually relevant anchor text). Show that closing just 15-20% of the quality gap (50-80 high-DR domains in your niche) would unlock estimated ranking improvements for your top 20 target keywords. This turns an overwhelming 3,000-domain gap into an achievable 90-day sprint targeting 50 specific domains.

**Problem: Link building agency claims to have acquired 200 links last month but DR hasn't moved and rankings are flat**
Solution: Run a link quality audit immediately. In Ahrefs, filter new referring domains from the reported period by: (1) DR score — how many are genuinely DR 30+? (2) Organic traffic of linking page — are these pages indexed and generating traffic themselves? (3) Link placement — editorial body links vs. sidebar/footer? (4) Site type — are any from clearly spammy link networks or article directories? Legitimate, high-quality links from a 30-day campaign will show measurable impact within 6-12 weeks. If links are DR <20 from thin content sites with zero traffic, you're paying for links that may actively harm your profile. Request an immediate campaign restructure or agency replacement.
