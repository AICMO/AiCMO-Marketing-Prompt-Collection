## Integration Tips

- **Salesforce:** Create a custom Campaign Type field with values: Executive Dinner / Roadshow / Trade Show / VIP Roundtable / Co-Sponsored. Use Campaign Influence (multi-touch) + primary campaign source for dual attribution. Build a Field Marketing ROI dashboard using the standard Campaign ROI report type filtered by Campaign Type. Add a custom "Field Marketing Touch" activity field on Opportunity to track event attendance at deal level.
- **HubSpot:** Use Marketing Events (native) or the Events tool to associate contacts with events. Run the "Contact activity" report filtered by event → then cross-reference with deals created/associated within 90 days using the Deals report with associated contact activity filter. Build a custom Field Marketing Dashboard using the report builder.
- **Marketo:** Use Programs (Event type) with Period Cost entered for each event. Use the Program Revenue Analyzer to calculate pipeline-to-investment ratio per program. Set up a smart campaign to auto-add the "Field Marketing Touch" tag to any opportunity associated with a contact who attended an event in the prior 90 days.
- **Cvent / Splash / Bizzabo:** Export attendee data with contact email, company, title, RSVP status, and check-in confirmation. Match against CRM on email → create a post-event list that auto-populates a follow-up sequence and logs an activity on the CRM contact record.
- **Google Sheets / Notion:** Use the provided ROI Scorecard table format as a monthly tracking template. Add a column for "Deal Velocity (Days)" to track how event attendance correlates with sales cycle length over time. Share with regional FMMs as a running scorecard.
- **Zapier / Make:** Trigger a "Field Marketing Pipeline Gap Alert" automation: when an event ends + 45 days pass with no opportunity associated to an ICP-matched attendee contact, create a task for the AE and notify the FMM via Slack.

## Troubleshooting

**Problem: "Our CRM attribution data is incomplete — reps don't consistently log event attendance as the opportunity source."**
Solution: Bypass rep-entered data with a reverse-match approach: (1) Export all event attendee lists with email addresses, (2) Export all opportunities created in the 90 days following each event, (3) Join on contact email → any opportunity with a contact who attended an event gets tagged as "field-influenced." This is more accurate than rep-reported source and can be automated with a Zapier workflow or RevOps script. For sourced attribution, use the stricter rule: contact had no prior opportunity when they attended the event, AND an opportunity was created within 60 days post-event.

**Problem: "Executive dinners show high pipeline but very small sample sizes — our CMO says the data isn't statistically meaningful."**
Solution: Pool data across multiple periods (run the analysis on trailing 12 months, not just the current quarter) to increase sample size. For events with fewer than 10 attendees, present a cost-per-opportunity and pipeline-per-attendee metric rather than a headline PSR, which requires more deals to be meaningful. Supplement with a qualitative narrative: interview 3 AEs who attended the highest-ROI dinners and document what made those specific events work. Present both the quantitative trend (even if directional) and the qualitative signal together for a stronger CFO argument.

**Problem: "Trade show numbers look terrible in isolation but Sales insists they drive long-term brand awareness that doesn't show up in 90-day attribution."**
Solution: Run a 12-month influence window analysis in addition to the standard 90-day sourcing window. Check how many trade show attendees appear later in won deals — even 6–12 months later — with any prior touchpoint. Also pull the "deals where trade show contact appears in the buying committee but isn't the primary contact" report in Salesforce. If the extended-window analysis still shows <2x PSR, the awareness argument is unsupported by data. Present both the 90-day and 12-month views to the CMO so the decision is data-informed rather than anecdote-driven.
