# ANALYSIS FRAMEWORK

## Module 1: Conversation Quality Scoring System

Design a standardized 100-point Call Quality Score (CQS) applied to every conversation. Score each dimension independently, then produce a composite score and percentile ranking against internal benchmark.

**CALL QUALITY SCORE DIMENSIONS:**

### Dimension 1: Opening Hook Effectiveness (0-25 points)

Sub-criteria:
- **Attention arrest** (0-8 pts): Does the first sentence create immediate relevance? Score: +8 if personalized to company/role/trigger event; +4 if generic but clear value framing; 0 if generic intro or sounds like spam
- **Curiosity gap** (0-7 pts): Does the AI create a reason to keep listening before the prospect can dismiss? Score: +7 if uses pattern interrupt or insight; +4 if uses question hook; 0 if uses feature pitch immediately
- **Disclosure handling** (0-5 pts): Is the AI disclosure (if required) handled in a way that doesn't cause immediate rejection? Score: +5 if disclosed upfront with confidence and value pivot; +3 if disclosed when asked without losing momentum; 0 if disclosed awkwardly causing hangup
- **30-second survival** (0-5 pts): Binary pass/fail — did the prospect engage beyond the opening? +5 if yes; 0 if immediate hangup or refusal

Failure signatures to flag:
- Prospect says "I don't have time" in first 15 seconds → opening didn't earn attention
- Prospect asks "Is this a robot?" immediately → voice naturalness or script pacing issue
- Silent hang-up before 10 seconds → number not recognized or caller ID rejection
- "Take me off your list" → likely a compliance or targeting issue, not a script issue

### Dimension 2: Discovery & Qualification Quality (0-20 points)

Sub-criteria:
- **BANT signal capture** (0-8 pts): Did the AI gather at least 2 of 4 BANT signals (Budget, Authority, Need, Timeline) when prospect was engaged? +2 per BANT signal confirmed
- **Pain question depth** (0-7 pts): Did the AI ask an open-ended pain question and follow up on the response? +7 if asked, listened, and bridged to value prop; +3 if asked but didn't bridge; 0 if used generic discovery or skipped
- **Adaptive listening signals** (0-5 pts): Did the AI respond to what the prospect actually said, or read the next script line regardless? +5 if responses were clearly contextual; +2 if partially contextual; 0 if obviously non-contextual (common with rigid dialog trees)

Failure signatures to flag:
- AI asks a discovery question but ignores the answer → rigid decision tree, not true conversational AI
- AI asks 3+ questions in a row → interrogation pattern, needs pacing adjustment
- Discovery phase took <30 seconds → insufficient qualification, low-quality meetings likely being booked

### Dimension 3: Objection Handling Intelligence (0-20 points)

Sub-criteria:
- **Objection acknowledgment** (0-5 pts): Did the AI validate the objection before responding? +5 if used "I understand" or equivalent with genuine empathy phrasing; 0 if immediately pivoted without acknowledgment
- **Objection response relevance** (0-10 pts): Was the response specific to the objection type? +10 if correctly categorized the objection type and deployed the right counter; +5 if deployed a generic but reasonable response; 0 if non-sequitur or read from wrong script branch
- **Pivot and continue** (0-5 pts): After handling the objection, did the AI successfully continue toward the CTA? +5 if yes; 0 if the conversation stalled or looped

Objection taxonomy to analyze against:
1. **Timing objections**: "Call me next quarter" / "Bad time right now" → correct response: curiosity-based timeline questions, not pushback
2. **Relevance objections**: "We don't have this problem" → correct response: insight challenge with data/customer reference
3. **Authority objections**: "Not the right person" → correct response: ask for referral to correct stakeholder, don't hang up
4. **AI/robocall objections**: "Is this a robot?" / "I don't talk to AI" → correct response: transparent acknowledgment + genuine value pivot, never deceive
5. **Price/commitment objections**: "We already have a solution" → correct response: differentiation question, not feature list

Flag: Which objection types have the lowest recovery rate in your data?

### Dimension 4: Value Proposition Delivery (0-20 points)

Sub-criteria:
- **Specificity to persona** (0-8 pts): Was the value prop tailored to the prospect's role and likely priorities? +8 if referenced role-specific pain or outcome; +4 if industry-specific; 0 if generic pitch
- **Outcome framing over feature framing** (0-7 pts): Did the AI lead with business outcomes (revenue, time, cost, risk) rather than product features? +7 if 80%+ outcome language; +3 if mixed; 0 if primarily feature-led
- **Social proof specificity** (0-5 pts): Was social proof used, and was it specific? +5 if named similar company/industry/result; +2 if generic "customers like you"; 0 if no social proof

Failure signatures:
- Value prop delivered in the first 15 seconds before any discovery → premature pitch syndrome
- Value prop uses product category language the prospect doesn't use → language mismatch, research the prospect's self-described problem vocabulary
- Value prop longer than 30 seconds without a question → monologue pattern, kills engagement

### Dimension 5: Call-to-Action Effectiveness (0-15 points)

Sub-criteria:
- **CTA clarity** (0-5 pts): Was the ask specific (specific time, specific day) rather than open-ended? +5 if offered 2 specific time slots ("Tuesday at 2pm or Thursday at 10am"); +2 if offered a day without time; 0 if "sometime next week" or vague
- **CTA timing** (0-5 pts): Was the CTA delivered at the right moment — after establishing value, not before? +5 if CTA came after at least one confirmed pain signal; +2 if timing was okay but slightly premature; 0 if CTA was the 2nd or 3rd thing said
- **Confirmation & handoff quality** (0-5 pts): If booked, did the AI confirm details, set next step expectations, and close the call professionally? +5 if confirmed name, email, time, calendar invite instructions; 0 if left ambiguity about next steps

## Troubleshooting

**Problem: Call Quality Scores are consistently high but booking rates remain low**
Solution: High CQS with low booking rates usually indicates a targeting problem, not a script problem — the AI is executing a good script on the wrong people. Audit ICP match rate for the week's connect list: what percentage of connects actually matched your defined ICP? If <60% are true ICP, the enrichment or list-building process needs fixing before more script optimization. CQS measures conversation quality given an engaged prospect — it cannot compensate for calling the wrong list.

**Problem: "Is this a robot?" objection is increasing week over week**
Solution: This objection typically spikes when: (a) call volume increases rapidly, triggering pattern recognition in prospect communities ("everyone at our company is getting calls from an AI this week"), (b) voice quality degrades at high volume due to API rate limiting affecting TTS quality, or (c) the script opener has become overly formal/robotic due to optimization for "professional" tone. Check the three causes in order: reduce call concentration per company, verify TTS audio quality at peak hours, and add more natural language variation to the opening (false starts, light filler words, natural pacing variation).

**Problem: Optimized scripts test well in first week but decay by week 4**
Solution: Voice AI script decay is real — once a script variant becomes dominant, prospects share experiences and resistance increases. Build a "script rotation library" of 4-6 opening variants and 3 objection handler variants per type, and rotate on a 2-week cycle even when a variant is performing well. This prevents the "heard it before" phenomenon that kills outbound programs. The highest-performing programs treat script optimization as a continuous process, not a one-time fix — plan for at least one new variant per script stage per month.
